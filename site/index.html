what it converts

drop a file and you only see the formats that make sense for it.

images
jpg · png · webp · heic · avif · tiff · bmp · gif · svg → pdf
video
mp4 · mov · mkv · webm · avi · gif · pull out the audio
audio
mp3 · m4a · wav · flac · ogg · opus · aiff
pdfs
→ images · merge · split · rotate · compress
archives
zip · tar · gz · 7z · unpack rar
anything
compress · strip metadata

it's tiny

a rust core with a native swift menu bar app. no electron, no hidden browser, nothing churning in the background. built to sit quietly on a base macbook air.

it's private

your files never leave your computer. there's no server to send them to. don't take my word for it — read the code.

it's yours

no account, no tracking, no paywall. missing a format? add it, open a pr, or fork it and make it your own.

make it yours

the whole thing is on github. clone it, change it, ship your own version.

$ git clone https://github.com/luiginotmario/cambio
$ cd cambio

if you make it better, open a pr and i'll ship it in the next release.
